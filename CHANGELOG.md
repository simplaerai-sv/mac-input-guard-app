# Releases

## 1.5.0

- Primary and backup microphone selection, automatic return to the primary, and built-in fallback.
- A normal settings window with current-input status, background operation, and controllable startup at login.
- English and Ukrainian UI, instant language switching, and importable JSON language packs, and export of a ready-to-edit translation template.
- Self-contained startup setup for a new installation.
- Universal binary for Apple Silicon and Intel, targeting macOS 13+.

Verified on Apple Silicon. Intel execution and a physical second-Mac installation have not yet been verified. The app is not Apple-notarized.
